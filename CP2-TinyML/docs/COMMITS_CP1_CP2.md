# Histórico de evolução CP1 → CP2

Adicione esta pasta ao repositório existente do CP1. Faça commits reais, separados por desenvolvimento, sem falsificar datas ou remover código histórico.

Sugestões, se ainda não realizadas:

```bash
git add CP2-TinyML/firmware/coleta_analogica CP2-TinyML/scripts
 git commit -m "feat(cp2): adicionar leitura analogica e coleta serial real"
git add CP2-TinyML/docs CP2-TinyML/README.md
 git commit -m "docs(cp2): registrar projeto publico e requisitos de evidencias"
git add CP2-TinyML/firmware/carrinho_integrado
 git commit -m "feat(cp2): integrar inferencia TinyML ao controle dos motores"
```

Inclua depois os CSVs reais, capturas autênticas e registros de testes em novos commits; faça `git push` na sua branch habitual. Este ZIP não altera nem confirma estado do GitHub.
